B. PARTNER FORM FULL ACCESSIBILITY (WCAG 1.3.5, 1.4.1, 3.3.1, 3.3.2, 3.3.3, 4.1.3)
   ─────────────────────────────────────────────────────────────────────────────────────
   Previously: Contact form fixed; PartnerForm.jsx untouched.
   Now: components/partner/PartnerForm.jsx fully remediated:
   - Unique id="partner-[field]" on all 6 inputs + captcha
   - sr-only <label htmlFor="partner-[field]"> on all fields
   - autoComplete tokens: name, email, tel, address-level2
   - aria-invalid={!!errors.[field]} on all inputs
   - aria-describedby="partner-[field]-error" on all inputs
   - Error <span id="partner-[field]-error"> linked to each field
   - Descriptive error messages with format examples
   - role="status" aria-live="polite" on statusMessage div
   - aria-hidden="true" on all decorative icons

C. TABLE REFLOW — ADDITIONAL FILES (WCAG 1.4.10)
   ─────────────────────────────────────────────────
   Previously: Only contact/table.jsx fixed.
   Now: All data tables site-wide:
   - app/research/[section]/ResearchSectionClient.jsx: skeleton + live table wrappers
   - app/sip-calculator/page.jsx: projections table + th scope="col"

D. NESTED <main> LANDMARK FIX — 31+ FILES (WCAG 4.1.1, 1.3.1)
   ───────────────────────────────────────────────────────────────
   Previously: Only layout.js had <main id="main-content">, but 31+ subpages
   also contained their own <main> elements causing duplicate landmark violations.
   Now: All nested <main> elements replaced with <div> across 32 files.
