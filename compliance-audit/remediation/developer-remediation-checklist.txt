CHECKLIST ITEMS & MAINTENANCE GUIDELINES
------------------------------------------------------------------------------------------------------------------------

[ ] ITEM 01: NON-TEXT CONTENT ALTERNATIVES (WCAG 1.1.1 / GIGW 5.2.1)
    - File/Component: app/layout.js, components/layout/Header.js, components/layout/Footer.js, components/home/*
    - Required Behavior: Every image (<Image>, <img>) must include descriptive alt text or aria-hidden="true" if decorative.
    - Acceptance Criteria: Screen readers announce image context accurately (e.g. "Ratnakar Securities logo").
    - Retest Procedure: Inspect DOM for alt attributes or test with NVDA/VoiceOver.

[ ] ITEM 02: INFORMATION AND STRUCTURE (WCAG 1.3.1 / GIGW 5.2.7)
    - File/Component: Entire app codebase (app/*, components/*)
    - Required Behavior: Maintain strict heading hierarchy (h1 -> h2 -> h3), semantic landmarks (<header>, <main>, <footer>), and semantic list/table tags.
    - Acceptance Criteria: Screen reader landmark navigation correctly lists Banner, Main, and Content Info regions.
    - Retest Procedure: Run landmark inspection using WAVE or Accessibility Developer Tools.

[ ] ITEM 03: KEYBOARD ACCESSIBILITY & TRAPS (WCAG 2.1.1 & 2.1.2 / GIGW 5.2.21 & 5.2.22)
    - File/Component: components/layout/Header.js, components/modals/*
    - Required Behavior: All interactive elements operate via Tab/Enter/Space. Modal dialogs and mobile drawers trap focus internally and close on Escape keypress.
    - Acceptance Criteria: User can navigate entire site without mouse input.
    - Retest Procedure: Perform full keyboard-only walkthrough using Tab, Shift+Tab, and Escape.

[ ] ITEM 04: VISIBLE KEYBOARD FOCUS (WCAG 2.4.7 / GIGW 5.2.33)
    - File/Component: app/globals.css
    - Required Behavior: *:focus-visible must maintain outline: 2px solid #2563eb !important; outline-offset: 2px !important;.
    - Acceptance Criteria: High-contrast focus outline appears around every focused control.
    - Retest Procedure: Tab through site and visually verify blue focus outline.

[ ] ITEM 05: FORMS & ERROR HANDLING (WCAG 3.3.1, 3.3.2, 3.3.3 / GIGW 5.2.44, 5.2.45, 5.2.46)
    - File/Component: app/contact/page.js, app/partner/page.js, components/modals/*
    - Required Behavior: Input fields have explicit <label htmlFor="...">, required indicators, autocomplete attributes, and role="alert" error announcements.
    - Acceptance Criteria: Invalid submissions announce errors clearly with correction guidance.
    - Retest Procedure: Submit empty and invalid form fields to trigger validation errors.

[ ] ITEM 06: DOCUMENT ACCESSIBILITY (GIGW Document Rule)
    - File/Component: public/images/*.pdf, uploads/*.pdf, app/downloads/page.js, app/investors/page.js
    - Required Behavior: All downloadable PDF files must be tagged, searchable (OCR text), and include document title metadata.
    - Acceptance Criteria: PDF screen reader test confirms reading order and text extractability.
    - Retest Procedure: Open PDF in Adobe Acrobat Pro Accessibility Checker.
