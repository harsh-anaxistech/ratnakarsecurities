REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 4.1.1.
Specifically: Correct Markup Structure. In content implemented using markup languages:
elements have complete start and end tags, elements are nested according to their
specifications, elements do not contain duplicate attributes, and any IDs are unique
within the page. Additionally, only one <main> landmark per page is permitted.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Duplicate DOM input IDs existed across modals and forms.
2. Nested <main> landmark tags: layout.js wraps all page output in <main id="main-content">,
   but 31+ subpages (sip-calculator, risk-calculator, products pages, investor pages,
   about, contact, downloads, etc.) each also returned a <main> element — creating
   invalid duplicate <main> landmarks on every page.
3. ResearchSectionClient.jsx had a nested <main> for its content column.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Duplicate IDs: Input/modal IDs prefixed with "contact-", "partner-", "modal-",
   "backoffice-", "choose-app-", "startup-" to guarantee uniqueness.

2. Nested <main> fix (31 files): All page-level <main> tags in subpages replaced
   with <div> tags. The sole permitted <main> landmark remains in layout.js:
   <main id="main-content" className="flex-1">.
