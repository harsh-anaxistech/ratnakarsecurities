--------------------------------------------------------------------------------
REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 3.3.3.
Specifically: Error Correction Suggestions. If an input error is automatically detected
and suggestions for correction are known, the suggestion is provided to the user, unless
it would jeopardize the security or purpose of the content.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Contact form errors only said "Invalid mobile" or "Invalid email" — no format hints.
2. Partner application form errors were even more generic with no format suggestions:
   - "Mobile number must be exactly 10 digits" (no example)
   - "Please enter a valid email address" (no format hint)
   - "City is required" (no example)
   - "Invalid captcha code" (no guidance on format)

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
All error messages in both forms now include:
- Descriptive text explaining the correct format
- Concrete examples where appropriate

Exact File and Code Locations:
- components/contact/form.jsx:L86, L92 (mobile + email format hints)
- components/partner/PartnerForm.jsx:L120-153 (all 7 validation error messages)

Code Snippets:
  ```jsx
  // Contact form
  newErrors.phno = "Please enter a valid 10-digit mobile number";

  // Partner form — improved messages with examples
  newErrors.email = "Please enter a valid email address (e.g. name@example.com)";
  newErrors.phone = "Please enter a valid 10-digit mobile number (e.g. 9876543210)";
  newErrors.timeslot = "Please select a suitable date and time slot for our call";
  newErrors.city = "City name is required (e.g. Ahmedabad)";
  newErrors.captcha = "Invalid captcha code. Please enter the 6-character code shown on the right.";
  ```
