--------------------------------------------------------------------------------
REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 1.1.1.
Specifically: Non-Text Content Alternatives. All non-text content presented to
the user has a text alternative that serves the equivalent purpose. Decorative
images that convey no information must use alt="" and aria-hidden="true" to
prevent screen reader redundancy.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Floating trading widget action icons and social media icons lacked text alternatives.
2. Menu navigation icons (shown alongside link labels in the megamenu) used descriptive
   alt text that caused redundant screen reader announcements (e.g., icon reads "Equity"
   immediately before the link text "Equity" is also read).
3. The mobile trading floating button (ScrollToTop.js) icon lacked aria-label on the link.
4. Decorative hover-text span in ScrollToTop.js was being read by screen readers.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Social / header icons: Added descriptive aria-label to anchor elements and
   aria-hidden="true" to the SVG icon children.
2. MenuIcons.js: All navigation icons changed to alt="" and aria-hidden="true"
   since they appear next to descriptive link text (decorative in context).
3. ScrollToTop.js (FloatingMobileTrading): Added descriptive aria-label to the
   anchor element; aria-hidden="true" on the Smartphone icon and hover text span.

Exact File and Code Locations:
- components/layout/Header.js:L241-246 (social icon links)
- components/layout/Footer.js:L145-149 (footer social icon links)
- components/FloatingMobileTrading.js (aria-label on link, aria-hidden on icon)
- components/layout/MenuIcons.js (all icons: alt="" aria-hidden="true")
- components/common/ScrollToTop.js (aria-label, aria-hidden)

Code Snippets:
  ```jsx
  // Social icons
  <a aria-label={social.label} ...> <Icon aria-hidden="true" /> </a>

  // MenuIcons.js - all navigation icons are decorative
  const getIcon = (src) => (
    <Image src={src} alt="" width={32} height={32} aria-hidden="true" />
  );

  // ScrollToTop.js floating mobile button
  <a href="..." aria-label="Start Mobile Trading – opens in a new tab" ...>
    <Smartphone aria-hidden="true" />
    <span aria-hidden="true">Start Mobile Trading</span>
  </a>
  ```
