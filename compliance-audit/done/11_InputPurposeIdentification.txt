--------------------------------------------------------------------------------
REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 1.3.5.
Specifically: Input Purpose Identification. The purpose of each input field that
collects information about the user can be programmatically determined when:
- the input field serves a purpose identified in the Input Purposes for User
  Interface Components list (e.g. name, email, tel, address-level2), AND
- the content is implemented using technologies with support for identifying the
  expected meaning for form input data.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Contact form inputs lacked autocomplete attributes.
2. Partner form inputs (PartnerForm.jsx) had no autocomplete attributes and no
   associated labels linking to the input fields by ID.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Contact Form: autocomplete tokens added to name, email, tel, department inputs.
2. Partner Form: Complete accessibility remediation:
   - Unique id on every input (partner-fullname, partner-email, partner-phone, etc.)
   - sr-only <label htmlFor="..."> on every input
   - autocomplete="name" on fullName field
   - autocomplete="email" on email field
   - autocomplete="tel" on phone field
   - autocomplete="address-level2" on city field

Exact File and Code Locations:
- components/contact/form.jsx:L277, L307, L334 (autocomplete attributes)
- components/partner/PartnerForm.jsx:L252-390 (full label + autocomplete implementation)

Code Snippets:
  ```jsx
  // Contact form
  <input type="email" autoComplete="email" ...>
  <input type="tel" autoComplete="tel" ...>

  // Partner form
  <label htmlFor="partner-email" className="sr-only">Email ID</label>
  <Input
    id="partner-email"
    type="email"
    name="email"
    autoComplete="email"
    placeholder="Email ID"
    ...
  />

  <label htmlFor="partner-city" className="sr-only">City</label>
  <Input
    id="partner-city"
    type="text"
    name="city"
    autoComplete="address-level2"
    ...
  />
  ```
