REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 3.3.1.
Specifically: Input Error Identification. If an input error is automatically detected,
the item that is in error is identified and the error is described to the user in text.
Errors must be programmatically associated with the corresponding field so assistive
technologies can announce them.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Contact form error messages were not linked to input boxes (no aria-describedby).
2. Partner application form (PartnerForm.jsx) had no accessible error association at all:
   - No input IDs for label linking
   - No aria-invalid on fields
   - No aria-describedby pointing to error messages
   - Error <span> elements had no ID for screen reader linking

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Contact Form (components/contact/form.jsx):
   - aria-describedby={errors.field ? "contact-[field]-error" : undefined}
   - Error <span id="contact-[field]-error"> ...message...

2. Partner Form (components/partner/PartnerForm.jsx) — full new implementation:
   - Unique id="partner-[field]" on every input
   - Matching htmlFor="partner-[field]" on sr-only labels
   - aria-invalid={!!errors.[field]} on every input
   - aria-describedby={errors.[field] ? "partner-[field]-error" : undefined}
   - Error <span id="partner-[field]-error"> ...message...
   - Decorative icons set to aria-hidden="true"

Exact File and Code Locations:
- components/contact/form.jsx:L242, L282, L312, L339
- components/partner/PartnerForm.jsx:L252-300, L304-390, L444-463

Code Snippets:
  ```jsx
  // Contact form
  aria-describedby={errors.name ? "contact-name-error" : undefined}
  <span id="contact-name-error">{errors.name}</span>

  // Partner form
  <label htmlFor="partner-email" className="sr-only">Email ID</label>
  <Input
    id="partner-email"
    type="email"
    autoComplete="email"
    aria-invalid={!!errors.email}
    aria-describedby={errors.email ? "partner-email-error" : undefined}
  />
  {errors.email && (
    <span id="partner-email-error" className="text-red-500 ...">
      {errors.email}
    </span>
  )}
  ```
