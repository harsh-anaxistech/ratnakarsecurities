REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 1.4.5.
Specifically: Images of Text.
If the technologies being used can achieve the visual presentation, text must be used
to convey information rather than images of text, except for:
1. Customizable: The image of text can be visually customized to the user's requirements;
2. Essential: A particular presentation of text is essential to the information being conveyed (e.g., logo, brand name, mockups).

This ensures users of screen readers, screen magnifiers, or customized style sheets
can fully access, resize, and style the text.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
Previously marked as Not Applicable. However, to guarantee complete compliance, the entire
codebase has been systematically scanned and verified. All headings, menu titles, banners,
and list items use actual HTML text styled with CSS instead of rasterized images of text.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Verifying that background images (such as page banners in HeroSection) use CSS positioning with HTML text overlaid on top.
2. Verified that the corporate logo (/images/logo/RSL_logo.png) is the only image of text used (which is an allowed exception for brand/logo names under WCAG 1.4.5) and includes proper alt description text.
3. Added a developer styling guideline to the main global stylesheet ensuring that future modifications always prefer styled HTML/CSS text over embedding text inside image assets.
