--------------------------------------------------------------------------------
REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 2.5.8.
Specifically: Target Size (Minimum). The size of the target for pointer inputs
must be at least 24x24 CSS pixels. Targets smaller than this must have spacing
(offset) of at least (12 - half the target size) CSS pixels on all sides.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Social and top header link items measured ~18x18px — below the 24x24 minimum.
2. Footer bottom copyright sub-links (Privacy Policy, Disclaimer, Terms, etc.)
   had small tap targets with no vertical padding, rendering them difficult to
   activate on touch devices.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
1. Header/Footer social icon links: min-w-[36px] min-h-[36px] applied to ensure
   comfortable touch targets above 24×24 minimum.
2. Footer copyright sub-links: Added py-1.5 inline-block to all Link and <a>
   elements in the bottom bar to expand clickable area without changing visual size.
3. Footer separator characters (|) marked with aria-hidden="true" so they are not
   announced by screen readers and don't appear as clickable targets.

Exact File and Code Locations:
- components/layout/Header.js:L241 (social link min-w/min-h)
- components/layout/Footer.js:L146 (footer social link min-w/min-h)
- components/layout/Footer.js:L347-352 (copyright sub-link py-1.5 inline-block)

Code Snippets:
  ```jsx
  // Social icon links (Header/Footer)
  className="... min-w-[36px] min-h-[36px] flex items-center justify-center ..."

  // Footer copyright sub-links
  <Link href={item.href} className="... py-1.5 inline-block">{item.label}</Link>
  <a href={item.href} className="... py-1.5 inline-block">{item.label}</a>

  // Decorative separator
  <span className="text-gray-400 select-none" aria-hidden="true">|</span>
  ```

--------------------------------------------------------------------------------
