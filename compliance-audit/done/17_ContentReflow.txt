--------------------------------------------------------------------------------
REQUIREMENT INTERPRETATION:
--------------------------------------------------------------------------------
The website must satisfy the accessibility condition described under WCAG 1.4.10.
Specifically: Content Reflow. All content must reflow to a single column at 320px
CSS pixel width (400% zoom) without loss of information or functionality, and without
requiring two-dimensional scrolling. Data tables that overflow horizontally must be
keyboard-accessible scroll regions.

--------------------------------------------------------------------------------
ORIGINAL FINDING (WHY IT FAILED):
--------------------------------------------------------------------------------
1. Financial data tables on the contact/escalation page overflowed horizontally without a
   keyboard-navigable scroll wrapper.
2. Research section tables (ResearchSectionClient) skeleton and live table views lacked
   accessible scroll wrappers.
3. The SIP Calculator projections table lacked a scroll wrapper and th scope="col" headers.

--------------------------------------------------------------------------------
IMPLEMENTED REMEDIATION & SOURCE CODE CHANGES:
--------------------------------------------------------------------------------
All table scroll containers across the site now have:
- tabIndex="0" — keyboard reachable via Tab
- role="region" — screen reader landmark
- aria-label="[descriptive label]" — announced to assistive tech
- focus:ring-2 focus:ring-blue-600 focus:outline-none — visible focus indicator

Additionally, all <th> elements in data tables now use scope="col" or scope="row".

Exact File and Code Locations:
- Location 1: components/contact/table.jsx:L13, L199
  (Escalation Matrix + SCORES table)

- Location 4: app/sip-calculator/page.jsx:L542 (Projections table wrapper + th scope="col")
