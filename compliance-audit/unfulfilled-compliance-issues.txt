POINT #1: INFORMATION AND STRUCTURE
--------------------------------------------------------------------------------
• Audit Status: NON-COMPLIANT
• Severity Level: CRITICAL
• GIGW 3.0 Reference: Clause 5.2.7
• WCAG 2.2 Reference: Success Criterion 1.3.1 (Level A)
• Affected Location(s): app/layout.js, subpages, financial data tables

1. EXACT FINDING / WHY IT FAILS:
   Website markup lacks semantic HTML5 landmarks (<main>, <header role='banner'>, <footer role='contentinfo'>). Heading levels skip hierarchy ranks (h1 to h3/h4). Financial report data tables on /downloads lack proper <th> headers and scope attributes.

2. REQUIRED DEVELOPER FIX / REMEDIATION:
   Wrap header in <header role='banner'>, main content in <main id='main-content'>, and footer in <footer role='contentinfo'> in app/layout.js. Fix heading structure (h1 -> h2 -> h3). Add <th scope='col'> to all data tables.

POINT #2: BYPASS BLOCKS (SKIP TO MAIN CONTENT LINK)
--------------------------------------------------------------------------------
• Audit Status: NON-COMPLIANT
• Severity Level: CRITICAL
• GIGW 3.0 Reference: Clause 5.2.27
• WCAG 2.2 Reference: Success Criterion 2.4.1 (Level A)
• Affected Location(s): app/layout.js

1. EXACT FINDING / WHY IT FAILS:
   Missing 'Skip to main content' link at the top of the body tag, forcing keyboard-only users to tab through 25+ header navigation items on every page transition before reaching main content.
