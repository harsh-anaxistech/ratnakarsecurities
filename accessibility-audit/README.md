# Ratnakar Securities - Digital Accessibility Audit & Remediation

## Executive Overview
This repository contains the complete Digital Accessibility Audit, Remediation records, real evidence screenshots, and client-ready report for **Ratnakar Securities Pvt. Ltd. (RSL)**.

- **SEBI Digital Accessibility Circulars**
- **GIGW 3.0** (Guidelines for Indian Government Websites)
- **WCAG 2.2** (Level A and AA Conformance)
- **IS 17802** (Parts 1 & 2)
